Farmer
-------
Farmer has 5 sections.
	1. Home
	2. Suggestions
	3. AI Assistant
	4. Community
	5. Consult

Main section is dashboard which is named "Home". It contains the overall info a farmer needs to be informed of. Rough structure is in /rules/ui/farmer/home.txt). The widgets mentioned there is encouraged to be changed if there's a better alternative, ex. bottom sheet might be replaced with full screen dialog or vice versa. Alert is shown below the top app bar and above farmer's overview to show it first priority. 

Suggestions section contains the personalized suggestions by AI for the farmer, such as <Something you should do>, <Tips and suggestive lessons based on personal problems or situations>. These are categorized by daily, weekly and monthly. once the suggestion is provided and its deadline finishes, it automatically disappears. And if the suggestion is something to do, not something to know or learn, then there should be an add task button beside the suggestion which will take to new task section with automatically input boxes filled by AI once clicked. Rough structure is in /rules/ui/farmer/suggestions.txt). 

AI assistant section is for help with custom prompts. It contains some pre suggested questions, and clicking them directly asks the AI that question, reducing manual typing effort. There should be chat history page that contains the history of previous conversations (that is cleared after 7 days). now it does not create a whole summary of all previous conversations as context for the new conversation, nor does it summarize the whole conversation of current chat for every new message response, instead it creates a context for the first message in new conversation, and then it keeps updating the context with each new message in that conversation, and for every response it uses that context to response. And it doesn't only give response but for further specifications, it can also ask questions (like giving options). For example: the prompt is "Way of cultivating", then it can ask "which crop or vegetable" or provide options based on ongoing seasonal crops and vegetables to select from. It has only access to farmers info (shadow copy), so that it can't change anything unintentionally. Rough structure is in /rules/ui/farmer/Ai_assistant.txt). Pre suggested prompts are given below (not to be taken word by word, only topic is given):
	1. Crop to cultivate (ex. What's good to cultivate now)
	2. Crop disease
	3. Farming guide
	4. Weather alert (ex. should I plant in x days or what will be the weather for next 5 days)
	5. Finance (ex. how to minimize cost)

Community section is where a farmer can see other farmers problems or situations and share their own problems and situations. It is kind of twitter platform, but simpler. Active task: post (text and optional image), passive: like, comment, askAI and report. there's no follow or add friend or share or copy link options. Top of the post contains the ID of the farmer or officer (if the post owner is an officer or expert, beside name "Expert" label is shown), clicking the profile shows a small dialog containing profile picture, name, phone number. Rough structure is in /rules/ui/farmer/community.txt).

Consult section is where farmer can book for expert's advice. At the top, if an meeting appointment is today, then it's shown on top with necessary details. Rough structure is in /rules/ui/farmer/expert.txt).

Profile section for farmer additionally contains tasks, appointments, posts, costs, crops etc <Card> widgets which open the respective sections (design for those windows is $generated)
