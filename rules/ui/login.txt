This file provides rough skeleton of the ui, not a complete design like background images description or suggestion, animations and transitions, color and effects about individual widgets, font size and styles, even using extra widgets like divider for clarity and smooth experience. That needs to be generated by AI following Tailwind CSS widget and text styles and color rules. Brand color is green, so not a random color palette should be applied.

`$generated` means that part will be generated by AI
platform: desktop, mobile
(mobile view is provided, desktop view should be created that fits with mobile view design)
theme: light, dark

Syntax
------
Without <> and First letter is capital -> Widget declarations -> ex. `Screen:`
With <> -> Widget definitions -> ex. <ScreenLogin@Screen> [parent widget is mentioned after @]
Lines starting with # -> comments
Without <> and first letter is small -> properties of the widget -> ex. text: "Hello World"
$something -> replace with the value of `something` variable

Mobile View is mainly divided into 3 parts.
    1. Top App Bar
    2. Main View
    3. Bottom App Bar
